# AIZU Foundation — Frontend Redesign

> Production-quality front-end redesign of [aizufoundation.com](https://aizufoundation.com/) as a college project.

---

## 🌟 Overview
A complete, interactive, and responsive web application redesign preserving 100% of the original content, numbers, links, and brand colors while delivering a modern UI/UX experience with smooth animations, custom micro-interactions, and a sleek Web3 aesthetic.

## 🛠️ Tech Stack
- **Framework**: React 18 + Vite + TypeScript
- **Styling**: Tailwind CSS + Custom Design System
- **Animations**: Framer Motion + GSAP
- **Smooth Scroll**: Lenis
- **Icons**: Lucide React
- **Routing**: React Router DOM

## 🚀 Features
- **Brand Aesthetic**: Faithful color palette (`#FF6B00`, `#F5EDD8`, `#2C1A00`) + Google Fonts (`Bricolage Grotesque`, `DM Sans`, `Space Grotesk`)
- **Pages**:
  - **Home**: Hero with floating cards, AIZU Coin allocation with count-up metrics, Programs preview, Trust marquee, Ecosystem bento grid, Gallery preview, Stats counters, Who We Are, Partners loop, 3D flip Country cards, CTA banner, and Footer.
  - **About Us**: Identity, alternating Origin Story and Vision cards with photography, Mission banner, and filterable 11-member team directory.
  - **Programs**: Community Care, Social Welfare, and Future Tech Education with impact metrics.
  - **Donations**: 6 member donation drives, Special Friends School interactive photo modal, News24 Telugu media highlight, and AIZU Coin ecosystem donations.
  - **Gallery**: Photo albums with interactive lightbox modal navigation.
- **Micro-Interactions**:
  - Lenis smooth scroll
  - Top reading progress indicator
  - Desktop custom cursor with trailing hover effect
  - Brand intro preloader on initial load / refresh

## 💻 Getting Started

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build
```
